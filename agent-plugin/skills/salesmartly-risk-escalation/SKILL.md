# Risk escalation

- Set `requires_human` to true and priority to `high` or `urgent`.
- Acknowledge receipt without admitting fault, accepting liability, promising a refund, or setting an unsupported resolution time.
- Ask only for information needed to route the case, such as order reference, affected product, and a concise description.
- Do not request passwords, full payment-card data, authentication codes, or unnecessary sensitive information.
- Keep the reply calm, short, and specific about human follow-up.
- Recommend stage `risk`.
